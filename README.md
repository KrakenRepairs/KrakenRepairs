# Kraken Repairs (Static Website Template)

A clean, modern static website template for a mobile electrical repair business.

## Pages
- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact + Web3Forms enquiry form

## Web3Forms setup
1. Create an access key at Web3Forms.
2. In `contact.html`, replace:
   - `YOUR_ACCESS_KEY_HERE`

## Hosting on GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**
4. Choose branch: `main` and folder: `/root`
5. Save, then open the Pages URL.

## Customisation notes
- Replace all instances of **Kraken Repairs** with your brand name.
- Update contact details in `contact.html`.
- Adjust colours in `assets/css/styles.css` under `:root`.
